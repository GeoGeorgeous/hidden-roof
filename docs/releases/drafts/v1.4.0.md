key bindings, bug fixes and performance improvements.

- **keys and settings**
  - a new Controls tab in Settings lets you rebind every key
  - your settings are now remembered between visits
  - crouch (hold or toggle) and tap twice to run are set in Controls
  - reset all puts back every key
  - Graphics shows your graphics card
  - Graphics has a performance test (a benchmark)
  - the mouse wheel changes the color
  - Q/E cycle through your caps, or change the width of the marker, roller and sponge

- **color picker**
  - click the mouse wheel (MMB) on any paint to switch to the closest color you carry

- **multiplayer**
  - rejoin within 3 minutes and you get your stepladder and what you carried back
  - strokes you made as the connection died are painted again once you're back
  - joining a session with a lot of paint is faster and no longer freezes the game
  - while you join or host, the menu shows how far the paint has loaded instead of PLAY; LEAVE cancels
  - the server no longer says it's full right after big sessions end
  - other players move smoothly on a bad connection
  - a connection that is slow only one way no longer drops
  - paint takes much less traffic
  - a reloaded or duplicated tab keeps the paint it sends
  - SAVE while reconnecting says to save again once you're back, instead of waiting forever
  - leaving while a session loads no longer leaves PAINT DETAIL locked, or says you're in a session with no connection
  - a game error ends the session with "the game hit an error", not "a new version is out"

- **fixes**
  - placing the stepladder no longer makes the game stutter
  - a page zoomed out in the browser no longer draws more pixels than your screen has
  - paint cleaned off with the sponge gives its memory back
  - browser shortcuts and zoom no longer get in the way while you play, and the mouse's back and forward buttons stay in the game; F5, F11 and Esc still work, in fullscreen too
  - you can stand on water tank roofs
  - shaking and spraying the can no longer work at once
  - right Shift runs too
  - a trackpad swipe changes one color at a time
  - K takes a screenshot only while you play
  - on a Mac, keys no longer stick after a Cmd shortcut
  - a game opened in a background tab loads
  - the loading screen says why when the game can't start
  - if something breaks while you play, the game says so and offers a reload, instead of freezing
  - paint runs trickle the same at any frame rate, so other players see them closer to how you do
  - the PLAY button shows its ESC key in Firefox and Safari, where Esc resumes
  - a trackpad swipe's sideways part no longer drops part of a color step
