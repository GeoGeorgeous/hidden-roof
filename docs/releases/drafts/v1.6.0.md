public sessions are here, multiplayer has a session list, and busy sessions run lighter.

- **public sessions**
  our first public session is ready and will run around the clock. follow our [Discord](https://discord.gg/CMG9tT5Q4u) to know when it's up!
  - its paint is saved on the server and stays from one visit to the next
  - house rules before you join

- **private sessions**
  hosting your own session is off for now: we'll say on Discord when it's back.
  - up to 4 players
  - the 5-letter code is now the session's password: the list shows the session, you type its code to join

- **multiplayer**
  - a session list: public and private sessions, with players, ping and the tools each allows
  - a new loading screen while the roof and its paint come in
  - a full session puts you in line: see your place, and you drop in as soon as a spot opens
  - close the tab and your seat goes to the next player within 15 seconds
  - a session can turn tools off: their items leave the map, and they're back once you leave
  - come back under the same nickname, on the same device or network: you get your tools back and stand where you were

- **performance**
  - the server sends you everything the others did in one go, so many more players fit before anyone lags
  - standing still sends less, so a quiet roof takes less of your connection

- **fixes**
  - the game runs in one tab at a time: a second tab says it's open in another tab
  - when the server goes quiet, the game reconnects within seconds instead of waiting for the browser
