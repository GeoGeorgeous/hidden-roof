paint dries, so a throw-up over dry paint runs less; new hints teach the controls as you play; and multiplayer tells you what's going on when the connection has trouble.

- **paint**
  - paint dries after a few seconds: spraying over a dry coat or a rolled wall no longer starts runs; holding the can on one spot still does
  - fewer runs: the roller lays a lighter coat, and caps run less, from the skinny cap (least) to the fat cap (most)

- **on screen**
  - subtitle-style hints teach you the controls as you play
  - turn them off, or show them again from the start, in Settings
  - pickups, and players joining or leaving the session, show as short notifications
  - a cleaner screen

- **multiplayer**
  - a player's name tag shows their nickname, what they're doing and how far away they are
  - leaving a session takes you back to the title screen with your own paint, as it was before you joined; the session's paint stays only if you saved it

- **performance**
  - other players' spraying costs less: the game reuses where their spray hits while their aim holds still
  - moving the stepladder near lamps no longer slows the game
  - no more stutter in the first moments after loading

- **links**
  - [Terms](/terms.html) and [Privacy](/privacy.html) pages
  - the pause menu links Discord, GitHub, YouTube, Instagram and TikTok, and a "buy me a coffee" link to [Ko-fi](https://ko-fi.com/D0Q7296HCP)

- **fixes**
  - a busy server no longer drops you when you reconnect; coming back online retries at once
  - statuses show when the server goes quiet, the connection is slow or you're reconnecting, and a "Reconnected" check once it's over
  - a lost session shows a dialog saying why (an update, a server restart, everyone left), with options to save your paint, reload or open the menu
  - a tab left open on an old version asks you to reload after an update, instead of saying the server isn't responding
  - nicknames: Latin letters and digits only, up to 16
  - if the game crashes, a dialog shows the error
  - screenshots (K) show the other players' name tags
  - links in Updates are clickable
  - without JavaScript, the page says the game needs it instead of loading forever
