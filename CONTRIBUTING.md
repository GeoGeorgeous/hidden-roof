# Contributing

Hidden Roof is source-available, not open source: see [LICENSE](LICENSE).

- **Bugs:** open a GitHub issue with the steps to reproduce it, what you expected, your browser, OS and GPU, and whether it happens in single player or multiplayer. For a multiplayer failure, attach the log from ESC → Multiplayer → COPY NETWORK LOG. Issues are public: the log holds your browser version and the nicknames in your session, so remove anything you don't want posted.
- **Security issues:** don't post them; email roof@hidden.haus.
- **Pull requests:** fork on GitHub, run `npm run check:quick`, then open the pull request. For anything bigger than a small fix, open an issue first. Read `AGENTS.md` before changing code.
- **Terms:** a pull request, patch or code you submit falls under Section 4 of the [LICENSE](LICENSE). You keep the copyright and give Hidden Haus a perpetual, royalty-free license to use it in any way, without credit or payment. Submit only your own work, nothing copied from GPL, AGPL or CC BY-SA sources (such as Stack Overflow or Shadertoy).
